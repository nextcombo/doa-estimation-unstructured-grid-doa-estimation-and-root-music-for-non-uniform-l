# [DOA Estimation] Unstructured Grid DOA Estimation and Root-MUSIC for Non-uniform Linear Arrays [with MATLAB Code]

The unstructured arrival direction (DOA) estimation for any geometrical one-dimensional nonuniform array (NUA) is addressed. Currently, the unstructured DOA estimation is solved via convex relaxation, which is only applicable to uniform linear arrays (ULAs). The sample covariance matrix of ULA has a Toeplitz structure, and the unstructured DOA is based on the Vandermonde decomposition of this matrix. The Vandermonde decomposition splits the Toeplitz matrix into its harmonic components, from which the DOA is estimated. Firstly, we propose an irregular Toeplitz matrix and an irregular Vandermonde decomposition (IVD), which generalizes the Vandermonde decomposition. The results show that IVD is related to MUSIC and root-MUSIC algorithms. Next, we extend the atom norm minimization for unstructured DOA (ANM) to NUA using the IVD. The resulting nonconvex optimization uses alternating projection (AP). Simulations indicate that the NUA/ULA solution based on AP is similar in accuracy to the convex relaxation of ULA's unstructured DOA.
Introduction
Estimating the arrival direction (DOA) of one or more signals to a sensor array is an important topic in array signal processing, with wide applications in radar, sonar, wireless communication, etc. Recently, the focus of DOA estimation has shifted from classical subspace-based DOA algorithms (including MUSIC, root-MUSIC, and ESPRIT [1]–[4]) to high-resolution [5], [6] and compression-based methods, such as compression DOA [7]–[9]. The advantage of compression methods is their high resolution (resolving nearby DOA) and only requiring one measurement snapshot.
The early compression DOA (DOA) technology approximated measurement values as linear combinations of a few DOA array patterns selected from a finite grid of possible DOA array patterns. However, due to grid mismatch, this technique would produce errors because the true DOA is not on the grid [10]. In response, there have been off-grid or gridless methods that exploit the sparsity in the atomic norms of the measurements [11]–[17]. The atomic norm is the minimum number of "atoms" required for the manifold in which the reconstructed vectors are needed, hence the gridless DOA is a continuous simulation of grid-based compression DOA.
Gridless DOA is an application of continuous compressional sensor (CCS) spectral estimation introduced in [11]. CCS has been extensively adjusted for related problems [18], [19], however, the atomic norm minimization (ANM) formula for one-dimensional arrays is the focus of this work [20], [21]. There are other similar gridless DOA algorithms, such as enhanced matrix completion based on CSS principles (EMaC) method [22] and gridless SPICE [14], but they are expressed differently from ANM. For a comprehensive review of CCS for DOA, see [23].
CCS solves a semidefinite programming problem (SDP), aiming to find the lowest rank Toeplitz matrix that can explain the measured results. Then, the Vandermonde decomposition of the best Toeplitz matrix is used to recover the frequency components of the signal [24]. When the rank of the Toeplitz matrix is less than sufficient, this decomposition is known to be unique [4]. In the context of DOA estimation, the parameters of the Vandermonde matrix (called harmonics) represent the DOA. The weakness of gridless methods lies in their limitation to regular sampling measurements only obtained from uniform linear arrays (ULAs).
The early work on extending unstructured DOA (uDOA) to non-uniform arrays (NUAs) focused on special array geometries, such as Minimum Redundancy Arrays (MRAs) [16], Coprime Arrays [25, 26], and Sparse Arrays [27]. Although uDOA is not typically extended to arbitrary array geometries, these special arrays constitute a small subset of NUA (as shown in Section III-B). The novelty of these arrays has never been their NUA geometry but rather the ability to resolve sources beyond those of the sensors forming the array. This work involves extending the usefulness of uDOA to ULA beyond any 1D geometry array. In this paper, "NUA" refers to any array within any one-dimensional geometrical body.
Recent efforts have been made to extend uDOA to NUA [28]–[30] by using Fourier series approximations to the manifold of NUA arrays. This idea can be traced back to "Fourier domain root-MUSIC" [31]. There are also older array interpolation techniques that convert ULA manifolds into NUA manifolds [32]–[38], but these techniques are limited by inherent trade-offs between precision and computational complexity. The proposed algorithm is based on a new matrix decomposition. Other recent works involve extending uDOA to higher-dimensional array geometries [39], [40], although the work presented here is limited to one-dimensional arrays.
The primary contribution of this work is the extension of the ANM formula for unstructured DOA to NUA based on a new matrix decomposition suitable for NUA measurements. We define two new matrices, the irregular Toeplitz and the irregular Vandermonde matrices. The term "irregular" refers to the irregular sampling of the wavefield by NUA. The irregular Toeplitz matrix is decomposed into irregular Vandermonde components, similar to the Toeplitz and Vandermonde matrices. This allows the extension of unstructured DOA (and root-MUSIC) to NUA.
The second contribution of this work is the computationally efficient solution for nonconvex rank minimization problems that arise from generalizing to NUA. Nonconvex optimization problems are often replaced with convex relaxations and solved using generic solvers such as the Alternating Direction Method of Multipliers (ADMM) [41]. However, extending to its convex relaxation is not straightforward for NUA. Instead, we propose the use of the Alternating Projection (AP) algorithm [43, page 606].
The AP algorithm has been used to solve CCS problems [44] and has been shown to be effective in formulating NUA AP to unstructured DOA through projection onto the irregular Toeplitz set [44]–[46]. Comparing the proposed AP solution with competing algorithms shows that it performs similarly or better while maintaining the ability to generalize to NUA.
The structure of this article is as follows: Section II contains an overview of unstructured DOA and related concepts, such as Vandermonde decomposition and root-MUSIC algorithm. In Section III, the IVD is introduced, which allows for the decomposition of any positive semidefinite (PSD) matrix into harmonics sampled at known irregular intervals (NUA sensor positions). The IVD enables the decomposition of non Toeplitz matrices into their harmonic components. In Section IV, modifications to the unstructured DOA problem are proposed to allow its application to NUA. A solution based on AP algorithm for reconstructing the unstructured DOA problem is presented. In Section V, the proposed algorithm is tested in simulated measurements of ULA and NUA. The results are used for DOA estimation but also applicable to a broader CCS problem, i.e., irregularly sampled signals.

Conclusion
Unstructured arrival direction (DOA) estimation considering arbitrary nonuniform array geometry is addressed. To achieve this goal, the irregular Vandermonde decomposition (IVD), which generalizes the Vandermonde decomposition for irregularly sampled signals (e.g., signals sampled from an NUA), is introduced. From the perspective of IVD, any covariance matrix can be considered as an irregular Toeplitz matrix and can be decomposed back into its irregular Vandermonde components. The decomposition can be utilized to extend unstructured DOA to NUA, as well as to expand larger continuous compression sensor (CCS) problems to irregularly sampled signals. The decomposition also leads to a new algorithm for extending root-MUSIC to NUA, previously realized through "Fourier domain root-MUSIC" and other algorithms.
An intuitive non-convex method for NUA DOA based on the Replacement Projection (AP) algorithm is proposed. The proposed algorithm is named AP gridless. Simulations of ULA measurements reveal that the performance of AP gridless is similar to that of its convex counterpart, ADMM. For NUA, ADMM cannot be generalized, and only AP gridless is applicable. It has been found that AP gridless is robust to noise, offers high resolution, and has a superior SNR compared to grid-based techniques.
